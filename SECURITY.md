# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/aliyilmazco/gitbrella/security/advisories/new),
or by email to okethis@gmail.com.

Include the gitbrella version, your OS, `git version`, the sync client, and
the steps that show the problem. You will get an answer within 7 days.

Of special interest: `check` writing to a repository or downloading a cloud
file, `fix`, `move-out`, `undo` or `prune-backups` losing data or acting
outside the repository, and anything that runs a command or follows a path an
attacker placed in a repository.
